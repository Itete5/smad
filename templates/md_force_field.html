Stillinger-Weber and Tersoff are both bond-order / many-body potentials designed for covalent semiconductors (a-Si, a-Ge). Unlike a simple pairwise potential, the bonding strength here depends on the local coordination and bond angles, correctly capturing the tendency of covalent networks toward 4-fold tetrahedral coordination.

Scope / honesty note: ReaxFF parameters come from extensive multi-parameter fitting against DFT reference data (bond order, over/under-coordination, lone-pair, torsion, hydrogen-bond, and charge- equilibration terms — typically hundreds of fitted constants per element combination). There is no closed-form way to derive a real ReaxFF force field on the fly, and this page does not compute any reactive energies or forces. What it does do is assemble a correctly-structured control-file template (charge method, cutoffs, QEq frequency) that you can pair with a real, published ffield.reax parameter file (e.g. from the original ReaxFF papers or the LAMMPS/Amsterdam Modeling Suite distributions) in an actual reactive MD run.
Where the real parameters come from

A production ReaxFF workflow looks like:

  1. Collect a DFT training set (bond dissociation curves, angle-bend curves, charges) for the elements involved
  2. Fit the bond-order, valence-angle, torsion, and charge-equilibration parameters against that DFT data (typically via a genetic algorithm / simulated annealing over parameter space — parameter-fitting codes are used for this)
  3. Validate the fitted ffield.reax file against held-out DFT reactions/structures not used in fitting
  4. Deploy in LAMMPS (pair_style reaxff) or similar with the control settings assembled here
BKS-type Buckingham potentials are the standard classical model for oxide glasses (a-SiO₂, aluminosilicates). The raw Buckingham form (A·e^(−r/ρ) − C/r⁶) has a well-known failure mode called the "Buckingham catastrophe": because the attractive −C/r⁶ term wins at very short range, the potential diverges to −∞ as r→0 instead of rising like a real repulsive core. Scope / honesty note: the parameters below are a generic, illustrative embedded-atom parameterization (Finnis-Sinclair-style √ρ embedding) — they are chosen to have physically sensible magnitudes for an FCC-metal-like system, but are not literature-exact values for any specific real metal. Production work should use a tabulated DYNAMO setfl/funcfl file fitted to real experimental/DFT data for the metal in question. What's genuinely computed here is the real EAM physics: a pairwise term plus a nonlinear embedding function of the local electron density, which correctly produces the coordination-dependent bond-softening (many-body saturation) that a purely pairwise potential cannot capture.

This is a genuine, small, trainable machine-learned interatomic potential: pairwise distances are expanded into Gaussian radial-basis descriptors (a simplified Behler-Parrinello-style symmetry function), and a linear model is fit by ridge regression to reproduce a reference potential. Error is reported on a held-out test set the model never saw during training — a real train/test split, not a cherry-picked fit. Limitation: this demo only fits the two-body part of the reference potential; a real MLIP for a many-body system (like SW/Tersoff's angular term) needs three-body (or higher) descriptors too — this is illustrative of the ML-potential concept and workflow, not a full production MLIP.
